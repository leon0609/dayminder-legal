Lovune · 念在支持

审阅更新：2026 年 10 月 26 日 · 尚未生效

本稿用于本轮待发布候选的支持页面审阅，尚不代表下载入口、设备兼容性或支持渠道已完成验收。

联系支持

当前配置的支持邮箱是 support@dayminder.app。本轮尚未核验收信与回复流程，因此不承诺回复时限。

了解内容处理和可选同步，请查看 隐私说明 / Privacy。

反馈问题时提供什么

描述操作和结果即可，不需要提供日记原文、私人照片或完整备份。

  • Lovune 版本和构建号（如可查看），设备型号及 iOS 版本。
  • 从哪个页面开始、做了哪些操作、预期结果和实际结果。
  • 如有错误提示，可提供不含个人内容的提示文字或已遮去个人信息的诊断。
  • 不要发送密码、账户凭据、日记内容、私人照片或完整导出包。

先留下这一刻

普通照片、文字和重要日子记录不要求 Apple Intelligence。没有智能建议时，可以自己写一句话或选择照片保存；普通记录不必先建立重要日子或回忆册。

Apple Intelligence 的设备端模型建议、系统日记建议（Journaling Suggestions）、普通文字识别（OCR）及本机规则解析是不同能力。系统日记建议只向应用交付你主动选择的建议。

模型增强受设备、系统、地区、语言和模型就绪状态影响。按实际提示检查条件，或继续普通记录。本轮尚无完整实机兼容清单，不承诺所有机型、语言或国行设备可用。

停止回望或提醒

应用内回望推荐可以选择“不再回顾”，隐藏推荐而保留记录；相关展示开关可在 Memory & Suggestions 中调整。

重要日子的通知另行管理：关闭该日子的提醒，或在 iOS 设置中管理 Lovune 通知。修改新日子的默认提醒，不会改变已有日子的提醒。

Apple 系统日记建议及其通知在系统设置中的“日记建议”里管理，入口名称可能随系统版本变化。它与 Lovune 自有提醒不是同一个开关。本轮尚未完成系统日记建议通知接回 Lovune 草稿的功能。

导出与恢复

设置中的 Backup & Storage 提供导出与 Restore Import。导出照片需主动勾选 Include photos；该选项默认未勾选。导出包可能包含私人内容，请自行选择保存位置或分享对象。

导入前先查看预览与冲突。Merge 会合并或更新匹配项；Replace All 会替换本机数据，并要求另行确认。候选版本的照片完整性、升级和恢复仍需实机验收，不能保证所有历史数据或原图都能恢复。

Restore Purchases 恢复的是既有 Apple 购买权益，不是日记、照片或备份数据。

免费使用与既有购买

本轮沿用本地核心免费、新销售关闭、保留既有购买恢复的规则。使用基础记录不需要先购买 Pro。

既有 Pro 的私有 iCloud 同步依权益和用户开关决定，默认关闭。同步、导出和分享的内容范围，请查看隐私说明。

体验与下载

本轮尚未核实可打开、可安装且与候选版本一致的体验或下载入口，因此本稿不提供下载链接、TestFlight 链接或二维码。

Lovune Support

Review updated: October 26, 2026 · Not in effect

This is support-page copy for review of the current unreleased candidate. It does not establish that download links, device compatibility or the support channel have passed validation.

Contact support

The configured support address is support@dayminder.app. Mail delivery and the reply process have not been tested in this review, so no response time is promised.

For content handling and optional sync, see 隐私说明 / Privacy.

What to include in a report

Describe what you did and what happened. Journal text, private photos and a complete backup are not needed.

  • The Lovune version and build number, if available, along with your device model and iOS version.
  • The starting screen, steps taken, expected result and actual result.
  • Any error message that contains no personal content, or diagnostics with personal information removed.
  • Do not send passwords, account credentials, journal content, private photos or a complete export archive.

Start with a moment

Ordinary photo, text and important-date records do not require Apple Intelligence. When intelligent suggestions are unavailable, you can write a sentence or choose a photo and save it. A standalone record does not require an important date or a memory book.

Suggestions from the on-device Apple Intelligence model, Journaling Suggestions, ordinary text recognition (OCR) and local rule-based parsing are separate capabilities. Journaling Suggestions supplies the app with suggestions you actively choose.

Model features depend on the device, operating system, region, language and model readiness. Follow the actual availability message or continue with ordinary recording. A complete physical-device compatibility list has not been validated for this candidate; availability is not promised for every model, language or device purchased in mainland China.

Stop resurfacing or reminders

You can dismiss an in-app memory recommendation with the option to stop resurfacing it while keeping the saved record. Related display options are available in Memory & Suggestions.

Important-date notifications are managed separately: turn off the reminder for that date, or manage Lovune notifications in iOS Settings. Changing the default reminder for new dates does not change reminders for existing dates.

Apple's Journaling Suggestions and its notifications are managed under Journaling Suggestions in system settings; the exact location may vary by OS version. This is separate from Lovune's own reminders. Continuing from a system Journaling Suggestions notification into a Lovune draft is not implemented in this candidate.

Export and restore

Backup & Storage in Settings provides export and Restore Import. Select Include photos if you want photos in the export; it is off by default. An export may contain private content, so choose its storage location or sharing destination yourself.

Review the import preview and conflicts first. Merge combines data or updates matching items. Replace All replaces local data and requires a separate confirmation. Photo completeness, upgrades and restoration still require physical-device validation for this candidate; recovery of every historical item or original photo is not guaranteed.

Restore Purchases restores existing Apple purchase entitlements. It does not restore journal entries, photos or backup data.

Free use and existing purchases

The current policy keeps local core features free, closes new sales and retains restoration of existing purchases. You do not need to buy Pro to make ordinary records.

Private iCloud sync for existing Pro customers depends on their entitlement and their own setting, which is off by default. See the privacy notice for the scope of sync, exports and sharing.

Try or download Lovune

No trial or download entry has yet been verified to open, install and match this candidate. This draft therefore provides no download link, TestFlight link or QR code.
